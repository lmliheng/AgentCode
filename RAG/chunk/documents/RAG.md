Milvus 是一款开源云原生向量数据库，专门解决海量高维向量的近似最近邻（ANN）检索问题，是大模型 RAG 系统的核心底座。
核心原理：将文本、图片等通过 Embedding 模型编码为高维向量，用 ANN 算法（如 HNSW、IVF）在牺牲极小精度的情况下换取百倍检索速度。距离度量常用余弦相似度（文本）或欧氏距离（图像）。
架构设计：采用计算存储分离架构，核心组件包括 Proxy（接入路由）、Root Coord（元数据管理）、Data Node（数据写入）、Index Node（异步建索引）、Query Node（内存检索）。所有变更通过消息队列同步，支持独立扩缩容。
操作要点：建 Collection（定义主键、向量字段、标量字段）→ 创建向量索引（HNSW 适合中小规模）→ 插入数据 → 加载到内存 → 执行向量搜索，可附加标量过滤实现混合检索。
RAG 配置：用户提问经 Embedding 模型转为向量 → Milvus 检索 Top-K 相关文档 → 拼接为上下文送入 LLM 生成答案。优化方向包括：合理分块、混合检索（BM25+向量）、Rerank 重排序、元数据过滤（时间/来源/权限）以及缓存高频查询结果。
作业：① 用 Docker 启动 Milvus，创建 Collection 并插入 10 条数据完成一次搜索；② 搭建最小 RAG 流程（Embedding→检索→LLM 生成）；③ 对比 HNSW 与 IVF_PQ 的适用场景。
