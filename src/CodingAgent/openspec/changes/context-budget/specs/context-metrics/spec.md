# Spec Delta

## Purpose

定义上下文体量的度量口径：区分「当前上下文大小」与「累计消耗」两个语义不同的口径，标注度量是实测还是估算，并明确预算判据的来源，使后续的压缩与限流策略有据可依。

## ADDED Requirements

### Requirement: 当前上下文大小与累计消耗分开可读

系统 SHALL 提供「当前上下文大小」这一度量，取值为最近一次模型请求实际消耗的输入量。该度量与「累计消耗」MUST 分别可读，MUST NOT 合并为单一数字。

#### Scenario: 当前上下文大小取最近一轮输入量

- **WHEN** 运行进行了多轮模型调用后需要读取当前上下文大小
- **THEN** 读到的值是最近一轮请求的输入 token 数，而不是各轮之和

#### Scenario: 两类度量分别可读

- **WHEN** 读取运行状态中的 token 度量
- **THEN** 能分别取得「当前上下文大小」与「累计消耗」两个值，不出现只有一个合并数字的情况

#### Scenario: 尚未发生模型调用

- **WHEN** 运行刚开始，尚未发起过模型请求
- **THEN** 当前上下文大小标记为未知，而不是报 0 或沿用默认值

### Requirement: 度量标注来源为实测或估算

每项 token 度量 MUST 标明其来源是实测（来自模型响应的真实用量）还是估算。系统 MUST NOT 把估算值当作实测值呈现。

#### Scenario: 来自模型响应用量时标记为实测

- **WHEN** 度量取自模型响应携带的真实用量
- **THEN** 该度量被标记为实测

#### Scenario: 需要推算时标记为估算

- **WHEN** 度量由推算得出而非取自模型响应
- **THEN** 该度量被标记为估算，与实测值可区分

### Requirement: 预算判据的来源明确且可配置

系统 SHALL 明确预算判据（阈值）的来源。判据 MUST 可由外部配置提供；未提供配置时 MUST 使用推导出的默认值，且该默认值的推导依据 MUST 可读。

#### Scenario: 判据由配置提供

- **WHEN** 外部配置提供了预算判据
- **THEN** 系统使用该配置值，不使用推导默认值

#### Scenario: 未提供配置时使用推导默认值

- **WHEN** 外部配置未提供预算判据
- **THEN** 系统使用推导默认值，且该值的依据可被读出

### Requirement: 度量本身不改变运行行为

本能力只产生度量与判据，MUST NOT 因度量结果而触发历史压缩、内容裁剪或停止运行。任何基于阈值的行为变更 MUST 由独立的、显式声明的能力引入。

#### Scenario: 度量超阈值不改变循环行为

- **WHEN** 当前上下文大小超过配置的预算判据
- **THEN** 运行循环的行为与未超过时一致，不自动压缩历史、不提前停止
